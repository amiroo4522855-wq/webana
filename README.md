# WEBANA | ویبانا

پایه فنی و سیستم طراحی وب‌اپلیکیشن ویبانا برای ساخت وب‌سایت بدون کدنویسی. پروژه فعلاً شامل زیرساخت فرانت‌اند، صفحه آغازین، پوسته مشترک، تم روشن/تاریک و مدیریت خطا است؛ داشبورد و ویرایشگر هنوز پیاده‌سازی نشده‌اند.

## اجرا

به Node.js نسخه `^20.19.0` یا `>=22.12.0` نیاز است.

```bash
npm install
npm run dev
```

سرور توسعه روی `0.0.0.0:5173` اجرا می‌شود.

## بررسی و ساخت

```bash
npm run typecheck  # بررسی TypeScript بدون تولید فایل
npm run lint       # بررسی ESLint
npm test           # اجرای تست‌های Vitest
npm run build      # بررسی نوع و ساخت نسخه تولید
npm run preview    # اجرای محلی نسخه تولید روی پورت 4173
npm run check      # اجرای متوالی همه بررسی‌ها و build
```

## مسیرهای فعال

- `/` — صفحه آغازین و معرفی کوتاه ویبانا
- `/start` — توضیح شفاف وضعیت نسخه اولیه و انتخاب واقعی حالت نمایش
- سایر مسیرها — صفحه ۴۰۴ با پیوند واقعی بازگشت به خانه

هیچ مسیر یا دکمه نمایشی برای ساخت پروژه، داشبورد یا ویرایشگر وجود ندارد.

## ساختار

```text
src/
├── app/             # اتصال مسیرهای اصلی برنامه
├── components/      # اجزای طراحی، آیکون‌ها، پوسته و مرز خطا
│   └── layout/      # هدر، فوتر و ناحیه محتوای مشترک
├── core/            # تنظیمات برند، زبان، تم و ابزارهای کوچک
│   └── theme/       # Context، Provider و منطق روشن/تاریک/سیستم
├── features/        # قابلیت‌های home، start و not-found
├── styles/          # Design Tokens و استایل‌های سراسری
├── tests/           # تست‌های راه‌اندازی، طراحی و تم
└── main.tsx         # نقطه ورود React
```

## سیستم طراحی

- فونت Vazirmatn به‌صورت محلی در bundle قرار می‌گیرد و درخواست فونت به CDN ندارد.
- رنگ‌های اصلی و معنایی، تایپوگرافی، فاصله، شعاع، کنترل‌ها، سایه‌ها، Breakpoint‌ها و Motion در `src/styles/tokens.css` متمرکز شده‌اند.
- اجزای مشترک فعلی: Button/ButtonLink، IconButton، Icon، Card، Badge، Tooltip و Select.
- اجزای جدید فقط هنگام نیاز واقعی اضافه می‌شوند؛ Modal، Toast، فرم‌ها و داده‌های نمایشی در این مرحله اضافه نشده‌اند.
- استایل قابلیت‌ها با CSS Modules و ویژگی‌های منطقی CSS نوشته شده تا توسعه LTR ساده بماند.

## تم و زبان

- زبان پیش‌فرض `fa` و جهت پیش‌فرض `rtl` است؛ نگاشت `en` به `ltr` در `src/core/i18n/config.ts` حفظ شده است.
- حالت‌های `light`، `dark` و `system` واقعاً روی کل رابط اعمال می‌شوند.
- انتخاب تم با کلید `webana-theme` در Local Storage ذخیره می‌شود و پس از Reload بازیابی می‌گردد.
- در حالت `system`، تغییر ترجیح رنگ سیستم‌عامل بلافاصله دنبال می‌شود.
- اسکریپت اولیه در `index.html` انتخاب ذخیره‌شده را پیش از رندر React اعمال می‌کند تا جهش رنگ کاهش یابد.
- `prefers-reduced-motion` برای همه انیمیشن‌ها و Transition‌ها رعایت می‌شود.
